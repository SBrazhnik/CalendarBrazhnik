«Зелёный ритм» — логотип-бабочка

svg/  — векторные файлы (масштабируются без потерь; надпись переведена в кривые, шрифт не нужен)
png/  — картинки с прозрачным фоном, число в имени — ширина в пикселях

icon          — иконка приложения (скруглённый квадрат), 1024/512/192/48
icon-round    — круглая иконка (аватар Telegram-бота, соцсети)
mark          — бабочка без фона для светлого фона
mark-on-dark  — бабочка для тёмного фона
mark-white / mark-black — одноцветные (печать, штамп, гравировка)
logo-horizontal / -dark — бабочка + надпись в две строки
logo-line / -dark       — бабочка + надпись в одну строку (шапка сайта, бланк)

Цвета: тёмно-зелёный #1F3A2B, зелёный #2F5D46, мятный #8FBF9F,
сливочный #F3F1E6, оранжевый акцент #F4A259. Шрифт надписи — Manrope Bold.
