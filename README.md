# Направления — статистика по Google Календарю для Android

Приложение считает по каждому направлению мероприятий:

- **дни** — сколько разных дней было хотя бы одно событие;
- **события** — сколько было мероприятий;
- **часы** — суммарное время;
- **сколько прошло** с последнего мероприятия (и когда следующее).

Периоды: неделя, месяц, год, всё время или любой свой период. Для каждого направления есть разбивка по месяцам года и список событий, у каждого показано, сколько дней прошло.

## Как определяются направления

По **цвету события** в Google Календаре. На экране «Цвета и направления» (значок карандаша) каждому цвету даётся название. Несколько цветов с одинаковым названием объединяются в одно направление. Ненужные цвета можно исключить из статистики.

## Синхронизация с Google Календарём

Полная, в обе стороны. Приложение читает и записывает события в календарь телефона, а Android синхронизирует его с Google:

- события из Google Календаря сразу видны в приложении;
- события, добавленные, изменённые или удалённые в приложении, появляются в Google Календаре.

Кнопка ⟳ запускает синхронизацию немедленно.

## Резервная копия и новый телефон

- **События** хранятся в Google Календаре. На новом телефоне они появятся сами после входа в тот же аккаунт Google.
- **Названия направлений и настройки** Android автоматически сохраняет в резервную копию на Google Диске и восстанавливает при переносе на новый телефон.
- Дополнительно: «Настройки → Сохранить копию в файл» / «Восстановить из файла» (файл можно хранить на Google Диске, в почте, Telegram).
- «Выгрузить события в CSV» — все события с направлениями в таблицу для Excel или Google Таблиц.

## Установка на телефон

1. Откройте страницу репозитория → **Releases** (справа) → последняя сборка.
2. Скачайте файл `Napravleniya-N.apk` на телефон и откройте его.
3. Разрешите установку из этого источника, если Android спросит.
4. При первом запуске разрешите доступ к календарю.

Новые версии ставятся поверх старой, данные сохраняются.

## Сборка

Каждое изменение в ветке `main` автоматически собирается GitHub Actions (`.github/workflows/build.yml`), готовый APK публикуется в Releases. Локально: открыть папку в Android Studio и выполнить Build → Build APK.

Минимальная версия Android — 8.0.
